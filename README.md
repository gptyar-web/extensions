# GPT Yar — پنل و Backend یکپارچه

این شاخه، پنل موجود را به Supabase منتقل می‌کند؛ مسیرهای مدیریت مشترک، کوکی، پروکسی و اطلاعات حساب حفظ شده‌اند. ورود فقط یک فیلد توکن `@` دارد. اطلاعات سرور و مجوز واقعی فهرست مشترکان بررسی می‌شوند و سپس نشست تصادفی، هش‌شده، هشت‌ساعته و قابل ابطال صادر می‌شود.

**وضعیت: کد قابل استقرار و آزمون محلی؛ هنوز استقرار یا تأیید عملیاتی سرویس‌های واقعی انجام نشده است.**

## ساختار

- `assets/app.js`: قابلیت‌های قبلی پنل با نشست Backend
- `assets/commerce.js`: ربات، کیف پول، سفارش، تمدید، تخفیف، قیمت، آموزش و نسخه
- `supabase/functions/gptyar-api`: ورودی Edge Function
- `supabase/functions/_shared`: اتصال‌های واقعی API، اعتبارسنجی، رمزنگاری، ربات و پردازشگر
- `supabase/migrations`: جداول، تراکنش‌های مالی، صف و RLS
- `tests`: آزمون دامنه، PostgreSQL و یکپارچگی محلی

## آزمون

```sh
npm ci --ignore-scripts
npm test
deno task check
```

پایگاه داده آزمون با PostgreSQL واقعیِ تعبیه‌شده در PGlite اجرا می‌شود. در آزمون یکپارچگی، فقط سرویس‌های خارجی بله و GPT Yar پاسخ‌های fixture دارند. هیچ آزمونی، پرداخت واقعی یا صدور واقعی توکن را اثبات نمی‌کند.

تنها نشانی عمومی Backend در `config.js` قرار می‌گیرد؛ هیچ کلید Supabase، توکن ربات، provider_token یا توکن مدیریت در این فایل قرار ندهید. پس از آماده‌سازی اولیه زیرساخت، عملیات روزمره از پنل انجام می‌شود.
