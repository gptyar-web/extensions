# گزارش تحویل GPT Yar

تاریخ: ۱۸ اکتبر ۲۰۲۶ — وضعیت: **پیاده‌سازی قابل بازبینی و استقرار؛ آمادهٔ فروش عملیاتی اعلام نمی‌شود.**

## ۱. تغییرات هر مخزن

| مخزن | تغییرات |
|---|---|
| `gptyar-web/extensions` | توسعه پنل موجود، Backend یکپارچه Supabase، Migration دارای ۲۵ جدول و RLS، نشست مدیریتی با توکن @، ربات، کیف پول، سفارش، صدور، تمدید، تخفیف، قیمت، آموزش، نسخه، گزارش و اعلان خطا؛ راهنمای اولیه و CI |
| `gptyar-web/gptyar-web.github.io` | حفظ ظاهر و پشتیبانی سایر پلن‌ها، دکمه خرید خودکار بله در هر دو صفحه، دریافت قیمت مشترک از دیتابیس، پخش‌کننده داخلی و آموزش‌های فعال؛ بدون بازنشر ویدیوهای قبلی |
| `gptyar-web/chatgpt` | حفظ ZIP قدیمی، افزودن سورس مبتنی بر فایل ارسالی ۴.۶.۵، تغییر محدود کانال بروزرسانی در پیش‌نویس ۴.۶.۶، بسته‌بندی با نشانی عمومی واقعی و آزمون عدم ارسال توکن به کانال عمومی |

Backend قبلی Cloudflare به عنوان مرجع تاریخی حفظ و استقرارش غیرفعال شده است. پنل جدید فقط از Supabase استفاده می‌کند؛ مسیرهای پیشین مشترک/کوکی/پروکسی/حساب در Backend جدید حفظ شده‌اند. تغییری در شاخه اصلی یا استقرار عمومی، صرفاً به دلیل آماده بودن کد، انجام نمی‌شود؛ تغییرات برای بررسی در شاخه‌های جدا قرار می‌گیرند.

## ۲. قابلیت‌های پیاده‌سازی‌شده در کد

- ورود فقط با توکن مدیریتی؛ بررسی سروری اعتبار، مجوز واقعی فهرست مدیریتی و تطبیق حساب. نشست هشت‌ساعته با هش، خروج و ابطال، Origin محدود، rate limit و کنترل replay.
- نگهداری رمزنگاری‌شده توکن‌ها با AES-GCM و کلید خارج از DB؛ ذخیره مجوز خودکار فقط پس از رضایت صریح مدیر در پنل. توکن کامل ربات و کیف پول از پنل قابل دریافت نیست.
- ثبت ربات @gpryarbot، getMe، Webhook دارای راز مستقل، بررسی اتصال و فعال/غیرفعال‌سازی؛ کنترل گفت‌وگوی خصوصی، فرستنده و رویداد تکراری.
- کیف پول مستقل از توکن ربات، حالت تست/واقعی، صورتحساب رسمی، PreCheckout سریع، رسید مستقل و استعلام تراکنش. ذخیره تنظیمات به معنی تأیید اتصال واقعی نیست.
- سفارش با قیمت سروری و snapshot، کد تخفیف تراکنشی، ظرفیت رزروشده، ثبت پرداخت یکتا و صف پایدار؛ دریافت نام/نام خانوادگی بعد از پرداخت.
- درخواست واقعی ساخت/تمدید به API GPT Yar با توکن سرور، ذخیره رمزنگاری‌شده توکن پاسخ، ارسال فقط به مالک بله. نتیجه نامشخص با شناسه یکتای سفارش تطبیق داده می‌شود و ساخت کورکورانه تکرار نمی‌شود.
- تمدید با همان شناسه/توکن و حفظ اعتبار باقی‌مانده، بررسی مالکیت، فرایند تأیید مالکیت اشتراک قدیمی توسط مدیر، ثبت سابقه عملیات.
- مدیریت قیمت/محدوده مدت، کد تخفیف درصدی یا ثابت/سقف/تاریخ/نوع خرید و تمدید، فایل ویدیو/تصویر/ترتیب/فعالیت، بسته ZIP/Manifest/CRC/SHA-256/انتشار/بازگشت نسخه.
- سفارش‌ها، پرداخت‌ها، تمدیدها، درآمد واقعی از DB، لاگ‌های فاقد Secret، رسیدهای مشکوک و اعلان بله برای مدیرِ متصل‌شده با پیوند یک‌بارمصرف.

هر ماه دقیقاً ۳۰ روز است. حداقل مبلغ صورتحساب یک ریال است؛ تخفیف بالاتر از مبلغ به subtotal منهای یک ریال محدود می‌شود. تراکنش‌های آزمایشی و اعتبارسنجی کیف پول در فروش محاسبه نمی‌شوند. محدودیت حساب از سرور یا تأیید مستند مدیر گرفته می‌شود؛ پیش‌فرض‌های ۲۰ کاربر و ۶۰ روزِ رابط افزونه به عنوان حقیقت سرور فرض نشده‌اند.

## ۳. آزمون‌های اجراشده

| مجموعه | نتیجه و محدوده |
|---|---|
| مخزن پنل | ۵۲ آزمون موفق؛ شامل ۴۲ آزمون جدید دامنه/PostgreSQL/یکپارچگی/DOM و ۱۰ آزمون رجوع به درگاه قدیمیِ بایگانی‌شده |
| مخزن سایت | ۳ آزمون DOM موفق؛ قیمت ارقام فارسی، تعرفه غیرفعال، عدم نمایش قیمت ساختگی در نبود Backend و کنترل‌های پلیر |
| مخزن افزونه | ۴ آزمون موفق؛ payload نسخه بدون توکن/شناسه دستگاه، حفظ مسیر قبلی در نبود تنظیم، Manifest و تزریق واقعی endpoint در ZIP |
| بسته واقعی آزمون | ZIP ساخته‌شده ۴.۶.۶، ۳۴ فایل، حدود ۱.۴ مگابایت؛ بررسی Manifest، فایل‌های ارجاع‌شده، decompression، CRC و کانال تنظیم‌شده با validator خود Backend موفق بود |
| بررسی Deno | بررسی تمام ماژول‌های JavaScript ورودی Edge Function با `checkJs` و تنظیمات مخزن موفق بود |
| امنیت DB | Migration روی PostgreSQL تعبیه‌شده PGlite اجرا شد؛ RLS، منع anon/authenticated و RPCهای حساس، مالکیت، یکتایی تراکنش، قفل تخفیف و اجاره صف آزموده شدند |

در آزمون یکپارچگی، handler و منطق اصلی و SQL واقعی اجرا می‌شوند؛ **پاسخ‌های GPT Yar و بله fixture مشخص‌اند**. این آزمون با پرداخت یا صدور واقعی برابر نیست. با یک توکن عمداً نامعتبر، مسیر اصلی validate به‌صورت HTTPS بررسی و HTTP 403 دریافت شد. هیچ مشترک واقعی ایجاد، تمدید یا حذف نشد.

آزمون تصویری مرورگر در این محیط کامل نشد: دانلود مرورگر نتیجه معتبر نداد و اجرای Chromium جایگزین با SIGTRAP متوقف شد. آزمون DOM جایگزین شده است؛ پخش واقعی codec، تمام‌صفحه، نمایش موبایل و نصب افزونه در Chrome هنوز آزمون پذیرش زنده لازم دارند.

## ۴. وضعیت استقرار Supabase

**پایگاه داده و Edge Function روی همین پروژهٔ متصل مستقر شدند.** با دستور صریح مدیر از پروژهٔ `isfahan-education-system` / `efibfevyiepkwpnobaro` استفاده شد؛ پروژهٔ تازه ساخته نشد.

- Migration نسخهٔ `20261018161002` / `gptyar_commerce` واقعاً اعمال شد: ۲۵ جدول با پیشوند `gptyar_`، RLS، توابع تراکنشی، ایندکس و قیمت‌های اولیه.
- سه bucket خصوصی `gptyar-videos`، `gptyar-posters` و `gptyar-releases` ساخته شدند؛ هنوز فایل واقعی در آن‌ها بارگذاری نشده است.
- تمام جدول‌ها و RPCهای GPT Yar برای `anon` و `authenticated` فاقد دسترسی‌اند. خواندن قیمت‌ها و اجرای گزارش با نقش واقعی `service_role` موفق بود؛ فروش و تعداد مشترکان صفر واقعی است.
- اثرانگشت دسترسی‌ها، policyها، ایندکس‌ها و توابع ۵۹ جدول قبلی قبل و بعد یکسان بود. سیاست‌های Storage قبلی نیز بررسی شدند؛ policyهای مجازکننده فقط bucket آموزشی قبلی را پوشش می‌دهند.
- بررسی Security Advisors پس از نصب، finding مرتبط با `gptyar_` نداشت. هشدارهای موجود سامانهٔ قبلی در محدودهٔ این تغییر اصلاح نشده‌اند؛ این نتیجه به معنی پاک بودن امنیت کل پروژه نیست.
- Edge Function جدید `gptyar-api` مستقر شد. نشانی واقعی در configهای عمومی پنل/سایت ثبت شده است؛ شاخه‌های اصلی سایت و پنل هنوز ادغام/منتشر نشده‌اند.
- آزمون HTTPS واقعی: `/health` و `/public/catalog` و بررسی بروزرسانی HTTP 200؛ مسیر مدیریت بدون نشست و Worker بدون راز HTTP 401. کاتالوگ تعرفه‌های واقعی DB را برگرداند و `sales_enabled=false` بود. وضعیت سلامت، تنظیم نبودن امنیت و Worker را صریح نشان داد.
- Secrets اختصاصی GPT Yar و زمان‌بندی Cron هنوز نصب نشده‌اند. مسیر ورود تا تکمیل تنظیمات امنیتی، `INITIAL_SETUP_REQUIRED` برمی‌گرداند؛ فعال‌سازی ربات و فروش واقعی انجام نشده است.

جزئیات راه‌اندازی باقی‌مانده در [SETUP-fa.md](SETUP-fa.md) است. توکن‌های ربات و پرداخت بعد از آماده‌سازی امنیتی فقط در پنل وارد می‌شوند.

## ۵. وضعیت ربات بله

**اتصال واقعی و Webhook ثبت‌شده نداریم.** توکن واقعی ربات وارد نشده است. قرارداد رسمی getMe/setWebhook/getWebhookInfo و دریافت رویداد در کد پیاده شده و با fixture آزموده شده است. فعال بودن ربات در محیط واقعی، بدون پاسخ واقعی API و اجرای Cron، ادعا نشده است.

## ۶. وضعیت پرداخت

**پرداخت آزمایشی داخل بله و پرداخت واقعی انجام نشده‌اند.** توکن تست رسمی در کد شناخته می‌شود و جریان آن محلی آزموده شده است. اعتبارسنجی کیف پول از پنل با صورتحساب ۱۰۰۰ ریالی انجام می‌شود؛ در حالت واقعی نیازمند تأیید مدیر و پرداخت واقعی است و هیچ اشتراکی نمی‌سازد. صدور حساب واقعی با پرداخت تست مسدود است.

## ۷. صدور و تمدید واقعی

**انجام نشده‌اند.** endpointها و قرارداد از سورس ۴.۶.۵ استخراج شده‌اند؛ موفقیت API با اعتبار مدیریتی واقعی هنوز بررسی نشده است. آزمون محلی موارد حفظ اعتبار، همان توکن، تطبیق نتیجه نامشخص و جلوگیری از صدور دوباره را تأیید کرده است.

## ۸. محدودیت‌های باقیمانده

- تنظیم اولیهٔ `GPTYAR_ACCOUNT_ID`، `GPTYAR_ENCRYPTION_KEY` و `GPTYAR_WORKER_SECRET` در Secrets و نصب/آزمون Cron لازم است. ابزار اتصال فعلی امکان ثبت Secrets پروژه را ارائه نمی‌کند؛ این مرحلهٔ زیرساخت باید یک‌بار در محیط امن انجام شود.
- توکن‌های واقعی باید بعد از استقرار از پنل ثبت شوند؛ هیچ‌کدام در کد، Commit یا پیام درخواست نشده‌اند.
- limits و شکل پاسخ API در حساب واقعی باید تأیید شوند. اگر سرور فیلدهای لازم را برنگرداند، فروش خودکار به‌صورت امن متوقف می‌ماند تا محدودیت معتبر مشخص شود.
- نسخه نصب‌شده ۴.۶.۵ از سرور اصلی update می‌گیرد؛ پنل جدید آن سرور را تغییر نمی‌دهد. بسته مدیریت‌شده یک بار باید ساخته/نصب شود. سازگاری نسخه ۴.۶.۶ با API اصلی نیازمند تأیید واقعی است. بسته‌های فاقد کانال متصل، قابل بایگانی‌اند ولی انتشارشان در کانال مدیریت‌شده مسدود می‌شود.
- فایل واقعی چهار آموزش با مجوز انتشار هنوز بارگذاری نشده است؛ زیرساخت آپلود آماده است. سقف پلن واقعی Supabase ممکن است از سقف کد پایین‌تر باشد.
- بازپرداخت خودکار از endpoint مستندنشده ساخته نشده است. رسیدگی و بازپرداخت واقعی از مسیر مجاز بله انجام و شناسه آن در پنل ثبت می‌شود.
- QA مرورگر/موبایل، پخش ویدیو از Storage و پذیرش end-to-end روی حساب آزمایشی معتبر باید بعد از اتصال زیرساخت انجام شوند.

## ۹. آمادگی عملیاتی

**خیر؛ تا تکمیل تنظیمات امنیتی، Cron و آزمون‌های زندهٔ فوق، شروع فروش واقعی توصیه/اعلام نشده است.** خروجی فعلی کد، Migration و آزمون‌های قابل اجراست؛ نتیجه Mock، اتصال یا استقرار واقعی معرفی نشده است.
